# Pro Meta E-Sports Design Guidelines

## 1. Brand Identity

Website Name:
Pro Meta E-Sports

Website Theme:
A modern and competitive e-sports club platform that promotes tournaments, players, achievements, and gaming community.

Design Style:
- Professional esports atmosphere
- Modern technology feel
- Clean and responsive layout
- Dark theme with blue/cyan highlights

---

# 3. Typography

## Recommended Font

Primary:
Lora

Usage:
- Website headings
- Important titles

Body:
Sans-serif recommended (Poppins / Inter)

Usage:
- Paragraphs
- Navigation
- Buttons
- Descriptions


Font Size Guide:

H1:
36px - 48px

H2:
28px - 36px

Body:
16px

Small text:
14px


---

# 4. Navigation Bar

Style:
- Dark navy background
- White text
- Cyan hover effect

Requirements:
- Same navbar across all pages
- Logo positioned on the left
- Navigation links aligned consistently
- Mobile hamburger menu required


---

# 5. Buttons

Style:
- Border radius: 8px
- Padding: consistent
- Smooth hover transition

Primary Button:
Background:
#03045E

Text:
White

Hover:
#0077B6


Examples:
- Join Now
- Register Tournament
- View Details


---

# 6. Cards

Used for:
- Tournament cards
- Player profiles
- Achievement cards
- Ranking sections


Style:
- Border radius: 12px
- Soft shadow
- Consistent padding
- Same image ratio


Card Structure:

Image

Title

Description

Action Button


---

# 7. Images

Requirements:
- Maintain consistent aspect ratio
- Use high-quality images
- Avoid stretched images
- Use rounded corners where appropriate


---

# 8. Layout Rules

All pages should:

- Use Bootstrap grid system
- Be mobile responsive
- Maintain consistent spacing
- Use the same navbar and footer


Spacing:

Small:
8px

Medium:
16px

Large:
32px


---

# 9. Animation Rules

Use animations only for improving user experience.

Allowed:
- Hover effects
- Fade-in sections
- Smooth transitions

Avoid:
- Excessive animations
- Distracting effects


---

# 10. File Naming Convention

HTML:
lowercase

Example:
- player-profile.html
- event-schedule.html


CSS:
- style.css


JavaScript:
- script.js
- storage.js
- api.js
